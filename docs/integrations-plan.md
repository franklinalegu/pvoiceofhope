# Integration Plan

## Forms
Current forms support mailto preview and Netlify-style attributes. Production options:
- WordPress form plugin
- Webflow Forms
- Netlify Forms
- Formspree
- Airtable/Google Sheets
- HubSpot/Brevo/Mailchimp

## Donations
Recommended providers to choose from:
- GiveWP for WordPress
- Stripe Checkout
- PayPal
- Donorbox
- CanadaHelps, if applicable

## Analytics
Recommended lightweight options:
- Plausible
- Google Analytics 4
- Google Search Console

## Content management
If non-technical updates are needed, migrate repeated content to a CMS:
- Blog posts
- Stories
- Events
- Programs
- Team members
- Partners
- Resources
